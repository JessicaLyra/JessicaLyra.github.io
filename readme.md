## Desenvolvimento

Requisitos: Node.js 20.19+ e npm.

```bash
npm install
npm run dev
```

Comandos disponíveis:

```bash
npm run lint
npm run build
npm run preview
```

O build de produção é gerado na pasta `dist/`. O projeto mantém as páginas `/`, `/en/` e `/planos.html` como entradas estáticas compatíveis com GitHub Pages.

O workflow em `.github/workflows/deploy.yml` executa lint, build e publicação do `dist/` no GitHub Pages. Nas configurações do repositório, selecione **Settings → Pages → Build and deployment → GitHub Actions**.

`npm run format` aplica o padrão Prettier; `npm run format:check` verifica a formatação.

## Estrutura

- `src/components/`: cabeçalho, rodapé e modal reutilizáveis.
- `src/pages/`: composição das páginas e componentes de cada seção.
- `src/hooks/`: hooks de comportamento compartilhado.
- `assets/css/`: estilos existentes do portfólio.
- `public/assets/img/`: imagens e ícones servidos pelo Vite.
